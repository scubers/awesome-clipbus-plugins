# 选题灵感

优先解决常见剪贴板任务，以下只作灵感。是否合并或新建看当前工程中插件的真实职责和用户意图，不按下面分组机械划分插件。

- 解码：Base64、JWT、URL 百分号、HTML 实体、Unicode 转义。
- 格式化：JSON、XML、SQL、CSV、TSV。
- 转换：时间戳、进制、单位、命名风格、颜色模型。
- 提取：URL 参数、邮箱、IP、UUID、坐标。
- 检视：字数、哈希、JSON 校验、文本差异、图片元信息。
- 生成：UUID、随机密码、二维码、占位数据。
- 清洗：去重、排序、空白整理、大小写转换、ANSI 清理。
- 解释：cron、正则、HTTP 状态码、权限位。
- 视觉：色块、渐变、Markdown 与结构化数据预览。

已有功能可以作为扩展起点；空工作区可以直接创建第一个插件。
