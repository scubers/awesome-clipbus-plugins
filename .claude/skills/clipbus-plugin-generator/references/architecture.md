# 阅读当前模板与 SDK

本文件提供阅读方向。具体路径、字段、接口和限制都从当前模板与实际安装的 SDK 文档确认。

## 工程组织

- 从模板或目标工程的说明和 package.json 识别安装、开发、构建、测试命令。
- 阅读 manifest 和入口，追踪能力声明如何关联到实现与输出产物。
- 分清演示业务与可复用的工程配置，特别留意构建脚本中仅适用于演示的映射。
- 确认宿主加载什么产物、开发预览如何挂载实际组件；采用目标工程自己的组织方式。

## SDK 契约

安装依赖后，从 SDK 文档地图定位本次需要的主题，确认：

- 检测、展示、主动变换和消息交互分别用什么贡献方式，是否适合本次需求。
- manifest 要声明什么，身份、命名空间、输入、写入、权限和生命周期有哪些约束。
- 运行端与页面端各能使用哪些 API，共享数据和契约如何组织。
- 重复复制、内容变化、失败与并发时的提交和状态语义是什么。
- 文件、网络、进程、数据大小及预览环境的边界是什么。

签名、类型、协议和限额查实际安装包的 API 参考；SDK 自己的教程与该参考冲突时，以 API 参考为准。
